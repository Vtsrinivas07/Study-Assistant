# 🧠 Neuron — The AI Learning Workspace

> **A Professional Learning Operating System**  
> Blending Notion, Obsidian, Duolingo, Apple Notes, and Linear.

---

## 🌟 Quick Start Guide

```bash
# 1. Navigate to project directory
cd Neuron

# 2. Install dependencies
npm install

# 3. Launch application (Frontend port 5176, Backend port 3004)
npm start
```

---

## ✨ Key Differentiators & Features

- 🖥️ **Three-Panel VS Code Style Workspace**: Left Sidebar (Spaces & Sessions), Center (Active Workspace), Right Sidebar (Streak & Timer).
- 🏷️ **Swiss Editorial Typography & Aesthetics**: Cream background (`#FAFAF7`), Indigo accent (`#4F46E5`), zero flashy blue gradients, high whitespace.
- 💬 **Natural Software Greeting**: Opens with *"Good Evening, Srinivas. Continue studying Machine Learning (72%)"* instead of a marketing hero.
- ⏳ **Multi-Step Intelligence Analysis**:
  `Uploading... -> Analyzing concepts... -> Detecting topics... -> Finding prerequisites... -> Building relationships... -> Generating quiz... -> Session Ready`
- 🕸️ **Interactive Knowledge Graph**: Clickable concept relationship tree connecting parent/child concepts (*Machine Learning -> Supervised -> Regression / Classification -> Neural Networks -> CNN / RNN*).
- 🃏 **Tinder-Style Swipeable Flashcards**: Swipe Left (*Review Again*) vs Swipe Right (*Know It*) with spacebar flip and arrow key shortcuts.
- 🎯 **Duolingo-Style Quiz**: Immediate option feedback animation (Correct Green vs Wrong Red) with educational explanations.
- 🔄 **AI Targeted Revision Roadmap**: Automated revision plan built from weak topics (*"Because you missed Neural Networks yesterday. Review takes 6 min."*).
- 🔥 **Learning Streak & Metrics**: Streak counter (🔥 7 Days), Concepts Mastered (82), Flashcards Reviewed (415), Weak Topics (3), Study Time (18h).
